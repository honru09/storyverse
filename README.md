# 织界 Storyweave

一个“由你的选择驱动”的手机端互动小说内测客户端，当前使用本地确定性剧情。

## 当前原型

- 首页：我的世界、正在生长的故事、继续阅读和合流入口。
- 造世向导：选择世界观 → 主角 → 能力与叙事温度 → 序章预览。
- 开局不再添加人为等待；每一步切换回到页首并聚焦当前问题。真实信息完全选填，草稿可跨页面恢复。
- 代入模式：可以把姓名、成长地、学校、单位、职业和一个重要的名字等“现实火种”带入主角；默认只做本地原型展示，接入后端时需要明确授权和隐私开关。
- 阅读器：初始准备两章，之后只领先阅读位置一章；遇到未决节点暂停，选择后才继续，避免跨分支浪费。正文不会提前写出用户尚未决定的行动。
- 连续阅读：手机底部目录支持回看、上一章和锁定未开启章节；翻章回到页首，首页进度跟随实际阅读位置而非已准备章节数。
- 可撤回的决策：更换旧选择前明确提醒后续会被替换；更改后旧章节及后续选择一并失效。读到终章后可开启新书或体验世界合流。
- 联机合流：两个世界线先列出冲突，再生成一部独立的第三本书，原书保持不变。
- 书城：社区作品以只读快照打开；自己的作品可发布匿名版本，现实火种不会公开。发布面板展示匿名后的标题，目录与分享面板使用原生模态焦点隔离。
- 本地书架：`storyweave:v2` 保存多本书、当前阅读位置、合流作品与发布快照，并兼容旧版草稿。
- 手机端优先：移动底部导航、粗线条触控卡片、固定底部操作区和安全区适配。

## 运行

Node.js 22.12+（推荐 24），使用锁文件恢复依赖：

```bash
npm ci
npm run dev
```

生产构建：

```bash
npm run build
```

回归测试：

```bash
npm test
```

当前为本地确定性原型，不调用收费模型。书城发布仅存本机，联机邀请仍为演示；尚未接入真实后端、多人房间或付费系统。

0.2 支持刷新/历史导航恢复、两本本地单人书合流、书架 JSON 备份恢复、损坏存档保护、存储失败反馈和跨标签冲突检测。完整浏览器验收：`npx playwright install chromium`，开发服务运行后执行 `npm run test:e2e`。见 [验收说明](e2e/README.md) 与 [商用上线计划](docs/RELEASE_READINESS.md)。

## 后续接入建议

真实 AI 需要将 `src/story-engine.js` 的同步模板调用改为异步服务，并增加授权、任务取消、失败重试与版本校验。建议接口起点：

```text
POST /api/story/create
POST /api/chapter/next
POST /api/choice/apply
```

模型层不要把整本小说反复塞进上下文。建议长期保存结构化 `WorldBible`、`CharacterSheet`、`StoryState`，每次只发送当前章节摘要、最近一到两章和当前决策；阅读第 N 章时后台预热第 N+1 章。合流时先生成 `MergePlan`（冲突清单 + 用户确认），再一次性生成合流章节。

## Google Cloud

服务端支持两种后端：本地默认使用 Gemini Developer API；Cloud Run 使用 `GENAI_BACKEND=vertex` 和服务身份调用 Vertex AI，不需要生产 API Key。完整资源、权限、部署与验证步骤见 [Google Cloud 部署](docs/GOOGLE_CLOUD_DEPLOYMENT.md)。

## 设计取向

手机端优先遵循 Apple Design 的直接反馈、清晰层级和可撤回路径：一个页面只保留一个主动作；重要卡片使用更重的边框与触控反馈；底部导航承载长期入口；动效在 `prefers-reduced-motion` 下自动降级。

### 纸页 × 潮汐 · 动效重构

- 暖白纸面、墨色粗线、橘色主行动；手机四入口，阅读时隐藏底部主导航。
- Lenis + GSAP 共用 ticker，增强桌面滚轮；手机和阅读页保留原生滚动。
- GSAP 管理页头/步骤过渡；React Bits AnimatedContent 使用官方源码，只让世界选项轻量入场。
- Vanta WAVES + Three r134 动态加载，限宽屏适配设备；手机、省流量、减少动态与渲染失败均使用静态潮汐画面。离屏/隐藏/卸载时释放 GPU。
- 右上角动效开关可随时暂停；动画不影响存档或剧情状态。
