# 替换视觉世界：方向准备

2026-10-22。用户已确认保留业务流程、全面重设计页面。此处保留候选推导，最终选择与实现约束以 PRODUCT.md 和 UI_SURFACE_BRIEF.md 为准。

## 机制与场景

用选项建立自己的小说，阅读时决定命运，两本原作产生独立第三本书。主要场景是拿起手机、进入正在读的世界，而不是管理 AI 任务。文化参照来自影视片单、出版封面、漫画、互动游戏与收藏型媒介。

首屏必须让读者看见故事的吸引力，同时立即找到“继续阅读”或“新故事”。不能用假数据证明吸引力。

## 排除的惯性

普通小说商城的密集同尺寸封面网格，以及它的反面——空旷暖白大标题加通用圆角功能卡——均不作为默认答案。旧暖白、海松绿、橘色轮廓系统已被用户否定；“织界”的纺织字面隐喻最多占一个候选，不自动将编织线作为主装饰。

## 七个独立候选（按产品关联排序）

1. **电影发行手册**：把正在读的故事作为一张有场景和标题张力的主海报，阅读位置成为片目注记。支持电影式世界入口和安静放映般的正文；风险是必须有足够好的封面资产。
2. **唱片收藏店**：故事像一张值得收藏的专辑，封面、侧脊、曲目式目录有明确物性；世界合流像联合发行。首屏一张主唱片加窄书脊列表，非伪3D货架。风险是音乐隐喻不得改变小说术语。
3. **漫画单行本扉页**：大胆中文标题、整版插画、硬边块面和章节分镜，用既有粗线要求做真实设计语言。首屏作品占据视觉主体，按钮作为版式部分。风险是不能误导为漫画阅读产品。
4. **旅行路线图册**：不是仪表盘图表，而是到达陌生世界的路线、站点和目的地；选择是岔路，两本书相遇形成新路线。首屏可读的路径与主场景共存。风险是图解不能盖过小说内容。
5. **独立游戏卡匣盒**：鲜明的色域、封套结构、可收集的作品与双主角联名封套。首屏选中一本即可进入，操作有实体按键的确定感。风险是避免像游戏商店或加无关游戏化。
6. **天文馆节目单**：大面积深色穹幕、柔和天体摄影与精确的节目布局；合流用两条可解释的轨道相遇。风险是不能退回发光霓虹、星空粒子和通用科幻模板。
7. **城市文化海报墙**：大块专色与摄影裁切的组合，有张力的字像内容本身，小说像城市里正在发生的事件。首屏不对称海报主次明确。风险是视觉密度需在手机阅读页明显退让。

## 共享边界

本次系统采用 cross-surface alignment：统一色彩、字体、封面与控件语言，首页/造世负责进入世界，阅读页负责可持续阅读。业务组件和数据协议不替换；Button、ReadingDialog、导航、封面原语复用；新原语至少需两个页面真实用途。移动端优先验证320/390px与桌面，不以横版设计压缩成手机。
