# 手机阅读流程动效复核

本轮主设计准则来自 `emil-design-eng/SKILL.md`（本机路径 `C:/Users/wangxr/.agents/skills/emil-design-eng/SKILL.md`），以使用频率、反馈目的、即时响应决定是否动画。GSAP 官方 `gsap-react`、`gsap-core`、`gsap-performance` 只负责实现方式与生命周期约束。Emil 的课程入口：[animations.dev](https://animations.dev/)。

产品原则：手机优先，阅读连续，选择明确。动效不得延后操作、隐藏待点击内容或改变阅读正文的位置。本轮未制作视频，也未将视频制作 Skill 加入阅读运行时。

## 机会判断

| 位置 | 使用频率与目的 | 决定 | 参数 / 行为 |
| --- | --- | --- | --- |
| 键盘导航、Enter / Space 激活、辅助技术点击 | 高频功能操作 | 立即显示 | 不创建标题或卡片入场动画；已有入场立即完成。 |
| 阅读章节标题 | 连续阅读中的重复操作 | 极轻反馈 | 指针操作保留 140ms 透明度变化、零位移；键盘操作立即显示。 |
| 造世步骤标题 | 一次流程中的阶段变化 | 保留轻量入场 | 指针操作 8px / 220ms / `power3.out`；内容从始至终可操作。 |
| 世界选项卡 | 帮助识别新内容 | 单次入场 | 8px / 220ms，键盘或触摸选择优先；结束后清理内联样式。 |
| 按钮按下 | 确认指针输入 | 保留现有反馈 | 使用现有 0.98 缩放；键盘模式应通过 CSS 取消缩放和过渡。 |
| 目录、备份对话框 | 偶发打开、明确层级 | 短入场、立即关闭 | 现有 180ms 入场；键盘打开应直接显示最终状态。 |
| 桌面滚轮惯性 | 辅助滚动手感 | 仅滚动期间运行 | 惯性结束释放 Lenis ticker；键盘接管时立即停止旧惯性。 |
| 手机触摸滚动、正文阅读 | 持续、主要任务 | 保持原生 | 不接入 Lenis，不创建阅读背景 WebGL。 |

## Before / After / Why

| Before | After | Why |
| --- | --- | --- |
| 动效策略只有设备与设置状态，不知道操作来自键盘还是指针。 | `input-modality.js` 在事件捕获阶段同步维护 `html[data-input]`，React 处理动作前即可读取。 | 避免状态更新晚一个 render，让键盘导航误启动入场。 |
| Enter / Space 进入造世或翻章时仍播放标题、选项卡动画。 | `useSceneMotion` 与 `AnimatedContent` 在键盘模式跳过创建动画。 | Emil 的键盘动作即时响应规则；焦点与内容无需等待。 |
| 用户按 Tab 时，画面可能仍在执行前一个指针触发的入场。 | 模态切换通知立即将已有入场完成并暂停；卡片的滚动触发器同时释放。 | 操作优先，键盘焦点周围的内容保持稳定。 |
| 仅依赖 `keydown` 会遗漏屏幕阅读器等无按键事件的激活。 | `click.detail === 0` 同样采用即时行为。 | 辅助技术激活也获得可预测的反馈。 |
| 将输入方式写进 React 动效依赖可能使切回指针时重播所有卡片。 | 输入方式作为同步查询与通知使用，不作为入场重建依赖。 | 只恢复未来操作的动效，已读内容不重新表演。 |
| 桌面 Lenis ticker 在页面静止时持续挂载。 | 仅滚轮惯性期间挂载，结束即释放；用连续动画时钟恢复下一次手势。 | 减少闲置工作，避免闲置时间导致下一次滚动跳变。 |
| 滚轮惯性未结束时开始键盘操作，两个滚动来源可能竞争。 | 键盘输入将当前滚动位置立即固定，再让浏览器处理键盘。 | 键盘操作应立即接管页面。 |
| 每次标题淡入都全局 `ScrollTrigger.refresh()`。 | 标题淡入不再刷新所有触发器。 | 标题只变透明度 / transform，没有改变布局几何。 |

## 不采用的候选

| 候选 | 不采用的理由 |
| --- | --- |
| 整页左右滑动、正文逐行 reveal | 高频阅读会重复等待，并改变文本视觉位置。 |
| 为每个决定增加弹跳或庆祝动画 | 选择本身已有明确状态；额外表演打断小说语气。 |
| 切换输入方式后重新播放当前页入场 | 用户只是在换输入设备，不是在进入新内容。 |
| 手机持续 3D 背景或全局惯性滚动 | 与轻量手机阅读、原生触摸和省电目标不符。 |
| 为普通按钮引入新的动画依赖 | 现有 CSS 按下反馈已覆盖用途。 |
| 使用视频渲染框架驱动应用导航 | MP4 制作与交互界面的响应频率、生命周期不同。 |

## CSS 配合点

输入属性由 `MotionProvider` 安装的观察器写入 `<html>`。已在 `styles.css` 合并 `html[data-input="keyboard"]` 样式：取消 transition / animation / smooth scrolling；键盘按下按钮不缩放；原生对话框打开时保持 `opacity: 1; transform: none`。用户选定「故事扉页」后，以上输入规则继续保留。

## 故事扉页补充

| Before | After | Why |
| --- | --- | --- |
| 世界用小图标表达，选中主要依靠底色。 | 同一世界的插画在选择、书架、预览与合流复用；选中立即出现勾选，图片在220ms内从1.04收至1。 | 状态先确认，动效只是收束注意力。 |
| 桌面存在装饰性Vanta波浪。 | 新页面不导入Vanta/Three，背景由静态叙事插画承担。 | 画面承担故事信息，减少加载与闲置渲染；不是用持续动效装饰阅读。 |
| 固定造世动作栏覆盖窄屏下方选择和模型告知。 | 继续/进入按钮随内容排列，设置与告知不被遮挡。 | 少一次界面干扰优于额外转场；动作仍可通过正常滚动触达。 |

常规按压80ms/松开160ms、标题140ms、阶段220ms、面板180ms保持。全局关闭动效和系统减少动态会停止CSS过渡；键盘触发不等待图片收束。

## 验证

- `node --test tests/input-modality.test.js tests/motion-policy.test.js`：23 项通过。其中 7 项新增测试覆盖同步输入识别、辅助技术点击、指针恢复、滚轮恢复、卸载清理、订阅清理及非浏览器环境。
- Chromium 独立测试上下文：冻结 GSAP 时间线后，键盘进入造世页时标题与卡片无待执行动画、无残留 transform / opacity；指针重新进入时可动画；Tab 中断立即完成；再次指针输入不重播当前卡片；辅助技术形式的点击保持即时行为。
- 之前的 Lenis 浏览器检查：滚动结束 ticker 为 0，重复滚轮手势正常；手动动效开关、系统减少动态和 390px 触摸环境原生滚动均通过。
- 上述浏览器测试使用独立测试上下文，不修改用户已有书架。本次未执行物理 iPhone / Android 的功耗、触摸与屏幕阅读器硬件验收。
