## 当前规则

- 系统字体、冷白画布、蓝色动作、大连续圆角、1px 边界与软阴影；原有世界插画及来源记录保持不变。
- 玻璃用于导航、操作分组、插画标签与面板。正文支持浅／暖／青绿／夜间／纯黑／跟随系统六主题，阅读视图与其控件同主题，离开后不影响其他页。
- 阅读隐藏全局顶栏与手机主导航，使用粘性阅读条和底部玻璃工具栏（目录、Aa 设置、查找、专注）；保留明确退出专注入口与安全区。
- 阅读字号 14–32 号实际采用 rem；系统黑体／设备宋体、四档行距、字重、页边距与对应正文行宽、段距、缩进、字距和对齐均可调整，不下载额外字体。
- 偏好与段落位置独立本机保存；字号与排版即时生效并保留锚点。位置书签不等于收藏，重写分支与只读副本隔离；查找只使用已开启的实际正文。
- 手机优先；至少 44px 命中区、16px 输入、safe-area、可见焦点。阅读保留原生滚动；逐屏是带内容重叠的即时纵向按屏移动，不是横向分页。700px 扩展布局，1050px 使用桌面侧栏。
- 常亮默认关闭，依赖浏览器 Screen Wake Lock 与设备授权，离开阅读释放；失败不妨碍阅读，也不替代系统亮度调节。
- 动效短、有限、可中断；GSAP 入场 220ms／8px，章节标题 140ms 仅透明度。键盘、关闭动效或减少动态直接终态。当前页面不导入 Vanta／Three 氛围。
- 低透明度／高对比／不支持模糊时保留实色可读表面。六主题覆盖当前阅读控件与桌面导航，不把阅读主题泄漏到其他页面。
- 原生 dialog 保留焦点、Esc、遮罩关闭与返回触发点；把手不是拖拽承诺。
- 账号未配置时禁用提交并保留游客路径；Google／邮箱能力需真实 Firebase 环境另行验收。登录不代表云同步、支付或多人书城上线。
- 保留选世界 → 建角色 → 能力与风格 → 阅读与决策 → 本机只读分享 → 双书合流，以及草稿、备份、改选失效与取消／重试行为。
