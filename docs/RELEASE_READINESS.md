## 已实现

### 开书、阅读与合流

- Hash 路由覆盖书架、向导、指定书籍、指定分享与合流，支持刷新、浏览器前进/后退和草稿恢复。
- AI 首章异步生成，支持取消和手动重试；取消或变更配置后旧结果不能新增书籍。
- 最多领先阅读位置一章；未决选择暂停预取。失败后等待明确重试，不自动循环发起收费请求。
- 改选使未来章节和选择失效；请求 key / 分支版本检查阻止旧响应写回。
- 六章体验支持目录、回看、选择、改选与终章；未开放章节不能跳过门槛。
- 选择两本不同单人书生成独立第三本书，两本原作保持不变；只有一本时示例角色明确标注。AI 合流上下文保留两部来源的有限世界规则、摘要和选择，而不是整本正文。

### 可选生成服务

- `GET /api/status` 提供配置状态；`POST /api/generate` 接收 `{ story, index }`，返回 `{ chapter, key, worldBible? }`。
- 本地模型凭据只在服务端读取；`npm run api`、`npm start` 和 `.env.example` 已提供。生产构建可由同一 Node 服务提供静态文件。
- 首章生成世界规则、结局方向和六章大纲；模型填写标题、正文、摘要，应用保留章节 ID、选项和分支协议。
- 服务器校验故事、章节顺序、未决选择和只读限制；对输入、模型输出、超时及服务错误提供有限、可重试的错误信息，不返回密钥或上游原始报错。
- 请求上下文使用世界规则、配置、已选分支、摘要和最近一章；有限的进行中去重、缓存、并发和频率控制已存在。这不等于账号额度、持久化计费或多实例全局限流。
- 仓库另有Vertex AI / Cloud Run支持及 [部署说明](GOOGLE_CLOUD_DEPLOYMENT.md)；云端成功来自来源任务的报告，本任务模拟测试不替代该证据。当前生成器仍通过环境配置选择单模型，双档分流尚未接线。

### 存储、分享与运行

- JSON 备份恢复校验大小、版本和嵌套字段，确认后替换；覆盖前本机保存 `storyweave:v2:recovery` 原始副本。
- 保存统一入口：读取失败、损坏存档或检测到其他窗口更新时停止覆盖；可导出临时书架、原始存档或显式载入最新数据。
- 容量不足等写入失败保留临时进度，支持重试；离页提醒仅在有未保存进度时触发。
- 校验正文、选项、主角、分享副本和草稿；错误边界提供重新打开与导出原始存档。
- 分享只保存本机只读副本；AI 分享预览实际正文，并要求勾选人工检查确认。脱敏替换不能保证清除全部间接身份线索。
- 移动端 manifest、图标和无 JavaScript 提示已存在；没有 service worker，不提供离线承诺。
- CI 配置执行安装、单元测试、构建与 Chromium 验收；没有以配置文件替代实际远端 Actions 运行证明。

## 运行与复验

Node.js 22.12+，推荐 24：

```bash
npm ci
npm test
npm run build
npx playwright install chromium
npm run dev -- --host 127.0.0.1 --port 5173
```

另一终端执行 `npm run test:e2e`。该脚本当前包括 journey、recovery 和 Gemini 模拟响应测试。默认地址 `http://localhost:5173`；可用 `TARGET_URL` 指定服务，用 `PW_HEADLESS=true` 运行无头测试。每次使用全新浏览器上下文，不清理用户原有书架。报告见 [验收说明](../e2e/README.md)。

实际模型模式需要本机配置 `.env` 并运行 `npm run api`。验证模型前应明确请求会产生真实成本；模拟测试不发送收费请求。

## 商用上线前仍需完成

1. 真实 iOS/Android、辅助技术、软键盘、安全区和低速网络验收；本地浏览器设计复核不能代替真机。
2. 优先补齐账号、会话与可信订阅权益，按正式双档模型规则服务端分流；继而服务端书籍归属、数据库、云同步、备份及恢复演练。
3. 获授权后的真实模型质量、延迟、失败与每章成本验证；内容处理、个人资料传输说明及长期剧情一致性验收。
4. 持久化任务、账号额度、实际usageMetadata（含推理token）、模型与套餐快照、JPY成本台账、幂等扣费、服务监控与多实例限流。以正式基线的未返赠金原价预算；当前缓存和本机并发限制不能代替这些能力。
5. 在线发布的权限、撤回、审核和隐私复核；真实合流的双方同意、固定父书快照与协作规则。
6. 支付回调校验、入账、退款、对账；真实部署、移动真机、安全和负载验收。未完成前不应收费上线。

## 已知限制

- localStorage 跨标签没有事务；原始载荷比较和事件检测不是数据库级并发保证。
- 清理浏览器数据或切换 origin 不会找回书架；目前跨设备依靠手动备份恢复。
- 备份/保存上限为 5 MiB；大量长篇正文不能无限堆积在 localStorage。
- 客户端取消能阻止写回，但不能承诺上游已接受的请求不再产生费用。
- 当前六章与预设决策骨架是内测范围，不代表无限长篇或自由多人生成已经完成。
- 2026-10-22 检查到本地 HEAD 为 `497f285`；本文件不证明其远端同步或 Cloud Run 部署状态。本次UI修改尚未提交。
