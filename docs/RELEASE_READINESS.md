# 0.2 客户端质量与上线计划

更新：2026-10-22。目标：手机端完整阅读流程、可靠存档、可复现验收。

## 当前可交付范围

当前是本地优先、六章预设剧情的内测客户端。这里的“流程跑通”指真实浏览器中能完成开书、阅读、选择、改选、完结、分享副本、创建第二本书、合流第三本书与继续阅读。AI、在线账号、在线书城、多人协作、支付尚未实现，不能将此版本标记为已经可收费商用。

## 本轮实现

- 页面 hash 路由覆盖书架、向导、指定书籍、指定分享和合流。刷新恢复当前页面；浏览器前进/后退可用；向导步骤与阅读章数随存档恢复。
- 合流支持选择书架中的两本不同单人书，保留两本原作，生成独立第三本书。只有一本书时提供明确标注的示例角色。
- 书架备份以 JSON 下载；恢复前校验文件大小、版本、嵌套字段与章节顺序，确认后替换。覆盖前本机保留 `storyweave:v2:recovery` 原始副本。
- 存储写入改为单一入口；读取失败、存档损坏和检测到另一窗口更新时停止覆盖。可导出临时书架及原始存档；可显式载入最新存档。保存失败时阅读器显示真实状态，离页提醒仅在有未保存进度时触发。
- 数据校验覆盖正文段落、选择项、双主角、发布副本和草稿；错误边界提供重新打开及导出原始存档。
- 旧版不含正文的分享引用不再显示为可读作品。
- 桌面 Lenis 按需使用 GSAP ticker，惯性结束即释放，手机保持原生滚动；短标题动效不会额外触发全局布局刷新。
- 依赖使用确定版本与锁文件；添加移动端 manifest、图标及 JavaScript 关闭提示。manifest 不等于离线能力，本版没有 service worker。
- GitHub Actions 配置执行安装、单元测试、生产构建、Chromium 端到端测试并保留失败截图。远端工作流是否通过以实际 Actions 运行记录为准。

## 本地运行

Node.js 22.12+，推荐 24。使用项目依赖中的 Playwright，无需依赖开发者电脑的全局 skill 安装。

```bash
npm ci
npm test
npm run build
npx playwright install chromium
npm run dev -- --host 127.0.0.1 --port 5173
```

在另一终端运行：

```bash
npm run test:e2e
```

默认测试地址是 `http://localhost:5173`，默认打开可见浏览器；每次使用全新浏览器上下文。可通过 `TARGET_URL` 指向已有服务，`PW_HEADLESS=true` 用于没有桌面的 CI。报告与截图位置见 `e2e/README.md`。

## 测试证据

- 单元测试覆盖故事分支、门槛、匿名化、预取、存档校验和存储失败恢复；以 `npm test` 当次输出为准。
- `e2e/journey.cjs`：390px / 320px 的主流程、刷新、前进/后退、分支改写、私密信息移除、只读副本、两本原作保留与合流书完结。
- `e2e/recovery.cjs`：实际浏览器文件下载/上传、确认与取消、损坏存档、拒绝存储和容量不足。
- 动效单独检查桌面两次相反方向滚动、惯性停止后 ticker 释放、手动关闭、系统减少动态与手机原生滚动。
- 尚无真机 iOS/Android、真实模型延迟、多人并发、收费与线上负载验收证据。

## 商用上线前必须完成

1. **服务端身份与数据归属**：账号、会话、数据库、服务端授权、备份和恢复演练；不能信任浏览器提交的书籍归属、支付状态或计费结果。
2. **真实生成服务**：将同步模板调用改为可取消的异步任务；模型凭据只在服务端；超时、重试、幂等、分支版本校验与额度扣减必须联动，返回旧分支的任务不能写入新分支。
3. **成本边界**：先保存世界规则、角色表、章节摘要、结局方向，按需检索最近相关片段；只预取一章，决策未定时暂停；计量输入/输出、缓存命中和失败重试。上线前测实际每章成本后再定价。
4. **发布与合流**：在线公开发布需要授权、删除/撤回、匿名化复核和内容处理机制；合流需双方同意，固定父书快照，生成独立第三本书。当前本机分享不能作为真实公开分享。
5. **收费和运营**：真实支付回调校验、幂等入账、退款、账单对账、监控告警；实际真机、性能和负载验收。未完成前只开放不收费的内测。

## 已知限制

- 本地存储跨标签没有事务；本版用原始载荷比较和 storage 事件检测冲突，但无法提供数据库级并发保证。多人模式必须由服务端处理版本和权限。
- 清理浏览器数据或切换 origin 不会自动找回书架；跨设备需手动备份恢复，直到有云同步。
- 当前 5 MiB 备份/保存上限匹配小型本地内测；大量长篇正文应迁移 IndexedDB 或服务端，不能无上限堆积在 localStorage。
- Three 的桌面异步包约 527 kB，构建会保留体积提示；手机和阅读页不加载它。
- GitHub Actions 文件只是已配置；没有凭借本地测试声称远端 CI 或生产发布成功。
