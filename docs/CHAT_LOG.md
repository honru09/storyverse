## 用户需求时间线

### 2026-10-14 前后：产品构想

用户提出创建一个 AI 互动小说平台：用户先选择世界观、角色、能力、家世等少量选项，系统直接生成一部属于用户的小说；阅读过程中只在关键决策点让玩家影响剧情，不要求用户反复输入提示词。

用户希望支持：

- 开局生成世界观、主角和剧情方向，后续按章节生成。
- 第一章生成时预取第二章，阅读第二章时预取第三章，降低等待感和 token 浪费。
- 用户可以把自己的姓名、家乡、学校、公司、职业、朋友和家人等信息作为主角代入素材。
- 两个用户可以把奇幻、修仙等不同世界线连接起来，生成一部独立的新书；两位主角和配角同时存在，原始书籍不被改写。
- 用户可以分享自己的书和合流书，其他用户可以在书城中阅读。
- 需要考虑留存：新奇的开局、连续阅读过程、关键决策和后期联机合流都是核心卖点。

### 2026-10-14：手机端与视觉要求

用户补充：项目主要做手机端；页面逻辑要简约；调用 Apple Design skill；使用粗线条和明显但克制的交互反馈。

### 2026-10-14：动效与库的要求

用户要求参考并组合以下项目：

1. Lenis：丝滑惯性滚动。
2. GSAP：网页动画逻辑。
3. Vanta.js：3D 动态背景。
4. React Bits：React 动画组件。

用户给出分层架构：Vanta 负责背景层，Lenis 负责滚动手感，GSAP 负责动画逻辑，React Bits 负责现成 UI 动效。随后要求重构设计、减少文字噪音、继续优化动效、交互逻辑、UI、排版。
